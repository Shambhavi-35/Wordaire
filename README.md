## 🚀 Installation

### Method 1: Download APK

1. Go to the [Releases](https://github.com/Shambhavi-35/Wordaire/releases) page.
2. Download the latest `app-release.apk`.
3. Open the downloaded APK on your Android device.
4. If prompted, allow installation from the source you downloaded it from.
5. Install **Wordaire**.
6. Start playing! 🎮

> **Note:** Android may ask you to allow installation from unknown sources because the APK is distributed outside Google Play.
